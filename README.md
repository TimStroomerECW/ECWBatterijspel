# ECW Batterijspel — GitHub Pages

## Publiceren
GitHub > Settings > Pages > Deploy from a branch > main > /docs > Save.

De map docs bevat de complete statische website. Er is geen buildstap nodig.
Het online scorebord gebruikt de bestaande server op https://batterijspel-energiehandel.brainypeony5.chatgpt.site/api/scores. Die server moet beschikbaar blijven; de spelwebsite zelf draait op GitHub Pages. Scores zijn gedeeld met de bestaande versie.

De GitHub-versie gebruikt Arial als systeemlettertype. De gelicentieerde Cera Pro-fontbestanden zijn niet opgenomen in deze openbare repository.

Bewaar relatieve paden: het spel staat onder /ECWBatterijspel/. Bij ieder bezoek begint het spel opnieuw.
